# Matem-ticas-III-Tabulaci-n
Actividad interactiva, en la que el alumno puede ir construyendo la tabla y ver inmediatamente cómo sus puntos van apareciendo en el plano cartesiano. Posteriormente puede tocar "comprobar" para comparar sus puntos obtenidos con la gráfica correcta. También cuenta con botón de "nuevo ejercicio"
